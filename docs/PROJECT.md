# مرصد | مرجع المشروع

المختبر يتيح رفع ملف HTML أو لصق الكود أو تشغيل العينة، مع إثراء اختياري من OpenRouter. صفحة المشاريع تدعم حسابًا محليًا بإيميل وكلمة مرور، ومدخلات إضافية، وفحوصات وتقارير محفوظة للمشروع. أرقام المراحل في السجل أدناه تخص الإصدار الأول. مراحل النسخة الحالية في [خطة التطوير والـChecklist](../work/plan.md) و[قبول الإصدار](RELEASE.md)، ومسؤوليات الأدوار والطبقات في [التصميم المعماري](ARCHITECTURE.md).

## المراحل ١–٣ · سجل النسخة الأولى



| المرحلة | المسؤول | المتطلبات | المخرجات ومعيار القبول |
|---|---|---|---|
| ١. عقد الفحص | محرك الوكلاء | كود HTML محلي وعينة معلومة النتائج | لكل وكيل مدخل وإجراء ومخرج وأداة وذاكرة. تحقق آلي من اكتشافات العينة ومن المدخلات النظيفة والفارغة |
| ٢. بيئة التشغيل | الواجهة وخدمة النموذج | عقد الفحص ومخطط طلب التلخيص | تشغيل الأدوار الخمسة من المتصفح، عرض الأدلة والمؤشرات وتصدير التقرير. مفتاح النموذج مؤقت، والتلخيص اختياري |
| ٣. القبول والتسليم | منسّق المشروع | تكامل الواجهة والمحرك والخدمة | تشغيل الاختبارات المحلية وتجربة المسار من المتصفح، ثم بناء نسخة الاستضافة والتحقق من النشر |

يقتصر التحليل على الإعدادات الظاهرة في نص HTML المدخل. تُقاس جودة الاكتشاف على العينة المرجعية، وتُقاس مدة التنفيذ وعدد الأدلة في كل تشغيل. لا توجد بيانات حقيقية لقياس الدقة العامة أو تكلفة النموذج.

اكتمل ربط المراحل. الاختبارات تغطي القواعد ومزوّد التلخيص البديل وحفظ النتائج عند فشله. أظهر تشغيل العينة في المتصفح خمس مراحل مكتملة وثلاث مطابقات بلا نتائج إضافية. الاتصال الحقيقي يعتمد على مفتاح المستخدم.

## مسار التنفيذ والذاكرة

| الدور | المدخل | الإجراء والأداة | المخرج |
|---|---|---|---|
| المنسّق | أعداد العناصر وإحصاء آخر فحص للجلسة عند الإثراء | يحدد مسارًا واحدًا أو فرعين، ويستخدم قرار الموديل لو صالح | قرار التوجيه ومصدره |
| التخطيط | قرار التوجيه ومجموعات العمل المتاحة | يقبل الترتيب من الموديل لو شامل، أو يستخدم الترتيب المحلي | فرع أو فرعان للتحليل |
| التحليل | خصائص HTML مستخرجة محليًا | يحسب المطابقات من سجل القواعد، ويقارن ترشيح الموديل بالحقائق لما يكون متاح | أحداث الفروع وحالة المطابقة |
| التحقق | كل الأدلة المحلية المطابقة | يعتمد النتائج من سجل القواعد ويحتفظ بكل موضع مطابق. مراجعة الموديل اختيارية | ملاحظات بالدليل المحجوب ورقم السطر والشدة والإصلاح |
| التقارير | النتائج المؤكدة والتغطية وتعليمات الإصلاح | يولّد الملخصين من قالب محلي، ويقبل ترتيب أولويات الموديل لو شمل القواعد المطابقة كلها | تقرير محفوظ وتصدير HTML باللغتين وJSON |

ذاكرة العمل هي حالة LangGraph التي تحمل قرارات التشغيل ونتائج الفروع. تحتفظ الجلسة بآخر ١٠٠ تقرير مكتمل، ومدة صلاحية ملف تعريف الجلسة ٣٠ يومًا. ذاكرة الإجراءات هي تعريفات القواعد والعقد ومساراتها في الكود. الذاكرة المستمرة هي التقارير المكتملة في SQLite المرتبطة بملف تعريف جلسة المتصفح. يستخدم المنسق عدد ملاحظات الفحص السابق كسياق محدود. إعادة فتح نفس المتصفح تتيح استرجاع التقارير طالما بقيت الجلسة والقاعدة متاحتين.

## حدود البيانات والقياس

يحلل FastAPI نص HTML على الخادم. استدعاءات OpenRouter الاختيارية تحتوي على بيانات بنيوية وأعداد وقرارات محددة. الدليل المحفوظ يحجب عنوان الوجهة والقيم الحساسة ويحتفظ برقم السطر. المفتاح موجود في ذاكرة الطلب. فشل استدعاء الموديل أو رفض شكله يفعّل القرار المحلي، ونتائج الأدلة تفضل ثابتة. بعض أخطاء الإعداد، زي المفتاح المرفوض أو اختيار موديل مدفوع بدون سماح، تظهر للمستخدم قبل تشغيل الفحص.

العينة المرجعية فيها ثلاث ملاحظات محددة عند الأسطر ٥ و٦ و٩. النجاح يتطلب تطابق القاعدة والسطر لكل منها وصفر ملاحظات زائدة. يُعرض قياس العينة عند تطابق المصدر المرجعي، ومع كل فحص يُسجَّل عدد القواعد والملاحظات واستدعاءات النموذج والمدة. نطاق النسخة يقتصر على سكربتات HTTP ونماذج HTTP وغياب integrity لسكربتات من ثلاث شبكات CDN.

## تشغيل التطبيق

من مجلد sentinel على Windows باستخدام Python 3.13 وNode.js:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
npm --prefix frontend ci
npm run build
npm start
```

افتح http://127.0.0.1:8765 واختار الملف، وسيب إعدادات الموديل فاضية لو عايز الفحص المحلي. للقبول الآلي استخدم `npm test`. يستعمل التشغيل المحلي React المبني من `frontend/`، والخدمة في `backend/main.py`، والرسم في `backend/graph.py`. يحتفظ المستودع بمدخل النسخة الأولى للتاريخ عبر `npm run legacy:start`.

يغير `PORT` منفذ التشغيل المحلي، ويحدد `MARSAD_DB_PATH` مسار ملف SQLite، وافتراضيًا `data/marsad.sqlite3`.

### عقد الفحص والتقارير في المختبر المحلي

- `POST /api/run` يستقبل `source` كنص، و`source_info` اختياري لتحديد النوع والاسم. واجهة المختبر ترسل `profile=extended` افتراضيًا. عملاء الـAPI بيحتفظوا بالسلوك الأساسي لو الحقل غايب. `GET /api/catalog` يعرض القواعد والأدوات. للإثراء ابعت `model` و`key` مع بعض. الحد ٢٥٠ ألف حرف ومليون بايت.
- الرد `application/x-ndjson` وفيه أحداث `step` ثم `complete` أو `error`. الخطوة فيها معرّف الفحص والدور والوقت ومصدر القرار. السجل يحفظ المكتمل. لو الطلب اتقطع قبل الاكتمال، استعادة حالة المهمة بتتضاف في Phase 4.
- `GET /api/history` يرجع آخر ١٠٠ تقرير في الجلسة. الفهرس يفلتر السجل ده ويعرض ١٠ تقارير في الصفحة. `GET /api/reports/{id}` يرجع التقرير الكامل ومصدره وتغطية القواعد والقياسات. البيانات الناقصة في تقارير الإصدار الأول تظهر كغير متاحة. عقد OpenAPI متاح في `/openapi.json`.
- `GET /api/reports/{id}/download` يقبل `lang=ar` أو `lang=en` لتصدير HTML، أو `format=json` لنفس بيانات تقرير التفاصيل. التفويض للتفاصيل والتصدير مربوط بجلسة التقرير.

منصة المشاريع بتستخدم `/api/platform` تحت نفس التطبيق. ليها حسابات OIDC، وقاعدة PostgreSQL، وسجل مهام وتقارير للمشروع، وتدعم الـ١٠٠ قاعدة ومقارنة الفحوصات والمراجعات. [تشغيل منصة المشاريع](PLATFORM.md)

### اختبار المتصفح

بعد بناء Vite، شغّل نسخة للاختبار على منفذ مختلف بقاعدة SQLite مؤقتة وفارغة. في الطرفية الخاصة بالخادم اضبط `PORT=8766` و`MARSAD_DB_PATH` على ملف الاختبار قبل `npm start`. ثبّت Playwright في بيئة الاختبار وثبّت Chromium عبر `python -m playwright install chromium`، ثم شغّل `python tests/browser_phase23.py`. استخدم `MARSAD_TEST_URL` لو اخترت منفذ محلي مختلف.

للاستضافة على خادم يدعم Python أو Docker، يحتاج مجلد بيانات SQLite إلى قرص مستمر، وتحتاج طلبات النتائج إلى دعم البث التدريجي. مثال لتشغيل الحاوية محليًا:

```sh
docker build -t marsad .
docker run -p 127.0.0.1:8000:8000 -v marsad-data:/srv/marsad/data marsad
```

استضافة النسخة الأولى تستخدم JavaScript Worker. النسخة الجديدة تستخدم عملية FastAPI طويلة التشغيل. نشرها على الإنترنت يتطلب وجهة استضافة تدعم هذه العملية وقرص البيانات.

## سجل القبول · ١٨ نوفمبر ٢٠٢٦

اكتملت المراحل ٤–٦ محليًا. نجح بناء React واختبارات المحرك والخدمة والتكامل. شغّل اختبار المتصفح نفس حزمة React وFastAPI وLangGraph وLangChain، مع بديل HTTP مؤقت لردود OpenRouter وقاعدة منفصلة. اختير الموديل من الإعدادات، واشتغل مسار الفرعين بستة استدعاءات. أظهر التقرير ثلاث مطابقات من ثلاث وصفر نتائج إضافية ونسختين للتنزيل. تحققت الاختبارات أيضًا من اختلاف مسار الفرع الواحد، وعزل تقارير كل جلسة، ورفض المفتاح غير الصالح. أمكن قراءة الكتالوج العام الحي، وتجربة استدلال حي تتطلب مفتاح صاحب الحساب. لم يُنشر إصدار Python على الاستضافة القديمة، ولم تُختبر صورة Docker على هذا الجهاز.
