# فحوصات الكود المصدري (PHP وJavaScript وPython)

الـ١٤ فحص دول (`SRC-01` إلى `SRC-14`) بيقرأوا ملفات الكود اللي المستخدم قدّمها في لقطة مستودع. مفيش كود بيتنفذ ومفيش حاجة بتتثبّت. كل لغة ليها تحليل صغير لمسار البيانات: مدخلات الطلب هي المصدر، وبعض الدوال المعروفة هي الوجهات، والدوال المنظِّفة وفحوصات التحقق بتوقف المسار. النتائج كلها `review_required`: ده تحليل أنماط جوه ملف واحد، مش إثبات إن الثغرة تتستغل. الكود في `backend/checks/source_code.py`، والمحوّل المسجّل اسمه `source-code` ومجاله `source`.

## المصادر والمنظِّفات والحراس

- **المصادر.** PHP: `$_GET` و`$_POST` و`$_REQUEST` و`$_COOKIE` و`$_FILES` وأجزاء من `$_SERVER`. JavaScript: `req.query` و`req.body` و`req.params` وأخواتها، و`location.search` و`location.hash` و`document.referrer`. Python: `request.args` و`request.form` وأخواتها في Flask وDjango، ومعاملات المسار في Flask وFastAPI، و`input()`.
- **المنظِّفات حسب نوع الوجهة.** `intval` و`(int)` وأشباهها تنظّف كل الأنواع. `mysqli_real_escape_string` تنظّف SQL فقط، يعني مخرج HTML يفضل ينبّه. `htmlspecialchars` للـHTML، و`escapeshellarg` للأوامر، و`basename` للمسارات.
- **الحراس.** `is_numeric` و`in_array` والمقارنة بنص ثابت وقوائم السماح تنظّف المتغيّر في الملف كله، لأن التحليل مش بيتتبع الفروع. الفحص بيفضّل تفويت نتيجة على إنذار كاذب.

## الحدود المعروفة

- التتبع جوه ملف واحد. القيمة اللي بتعدّي في دالة أو ملف تاني بتضيع.
- JavaScript بيتقرا بتعبيرات نمطية مش بمحلل لغة. Python بيستخدم `ast` القياسي. الملف اللي مش بيتفسّر (Python بخطأ صياغة) بيتخطّى.
- الملفات الأطول من ٤٠٠ ألف حرف أو اللي فيها أسطر أطول من ٤ آلاف حرف (مثل المصغّرة) بتتخطّى، وكذلك المسارات اللي فيها `fixtures` أو المدرجة في `fixture_paths`.
- SRC-08 في PHP بيطلع لما الملف بيقرأ طلب وبيكتب في قاعدة البيانات ومفيهوش كلمة token أو csrf. لو فيه middleware عام في ملف تاني بدون الكلمة دي، الفحص هيطلع نتيجة محتاجة مراجعة.
- مش مغطّى: تتبع بين الدوال، قوالب HTML (`|safe` وأشباهها)، NoSQL، التفويض (IDOR)، منطق العمل، ثغرات المصادقة، كسر القوة الغاشمة. دي محتاجة تحليل أعمق أو مراجعة بشرية.
