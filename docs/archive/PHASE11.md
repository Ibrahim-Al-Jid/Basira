# Phase 11 | مصادر الفحص وربط الأدلة

من **الفحوصات ← فحص جديد** اختار المشروع والمصدر. السياسات المحفوظة للمشاريع بتحدد الأنواع المعروضة. المالك أو المدير يقدر يفعّل الأنواع من **إدارة المشروع ← أنواع المدخل المسموحة**. [خطة المرحلة](plan-19-phases.md#phase-11)

| المصدر | اللي مرصد بيعمله |
|---|---|
| ZIP | يقرأ الملفات النصية المدعومة ومنها CSS. جدول «ملفات اللقطة» في تبويب التغطية يوضح المقروء والمتخطّى وسبب التخطي، والقائمة الكاملة في JSON. PDF بيوضح الأعداد وأول ثمانية ملفات. |
| GitHub | المالك أو المدير يربط مستودعًا بالمشروع من اتصالات المؤسسة. اختار GitHub في الفحص واكتب SHA كامل من ٤٠ خانة. مرصد يحفظ اسم المستودع ومعرّف الاتصال والـSHA وبصمة الأرشيف. |
| HAR | مراجعة الاستجابات المحفوظة والمنقّحة، مع خيار تسجيل مرجع الموقع. |
| ZAP | استيراد تقرير Traditional JSON محفوظ لأصل HTTP(S) محدد. الاستيراد يراجع أربعة معرّفات قواعد سلبية مدعومة ويعرض النتائج كملاحظات مستوردة تستلزم مراجعة. |
| OpenAPI | مراجعة JSON محلي بإصدار 3.0 أو 3.1. التقرير يعد العمليات، وأنواع المصادقة المعلنة، ومتطلبات المصادقة والمراجع غير المحلولة. |

حد ZIP الحالي ٢ ميجابايت قبل الفك، و٨ ميجابايت بعد الفك، و٢٠٠ عنصر ومليون بايت للملف داخل اللقطة. تُقرأ ملفات CSS ضمن الأدوات العامة للملفات المؤهلة. تفاصيل ما ينطبق من قواعد لكل نوع تظهر في التغطية. مراجعة HAR وZAP وOpenAPI تستخدم المحتوى المحفوظ. عناوين الموقع والـAPI ومراجع OpenAPI الخارجية تبقى بيانات وصفية. [مدخلات الفحص](WORKSPACE-INTAKE.md) · [ZAP Traditional JSON](https://www.zaproxy.org/docs/desktop/addons/report-generation/report-traditional-json/) · [OpenAPI](https://spec.openapis.org/oas/v3.1.1.html)

## اتصالات GitHub

1. مشغّل مرصد يجهّز GitHub App بصلاحية قراءة **Contents** وMetadata ويثبّته فقط على المستودعات المعتمدة.
2. في إعداد البيئة الخاص، عيّن `MARSAD_GITHUB_APP_ID` و`MARSAD_GITHUB_APP_KEY_PATH` لمسار ملف PEM خاص خارج المستودع. عيّن `MARSAD_GITHUB_INSTALLATIONS` ككائن JSON مفاتيحه معرّفات مؤسسات مرصد وقيمه قوائم معرّفات التثبيت المخصصة لها. كل تثبيت له مؤسسة واحدة.
3. شغّل Compose بإضافة `-f compose.github.yaml`. الـPEM يُركّب للقراءة فقط في خدمة التطبيق. المالك أو المدير يختار **الحساب ← اتصالات المؤسسة ← GitHub** ويربط مشروعًا بمستودع متاح للتثبيت.

مرصد يطلب توكن تثبيت مؤقت ومحدود إلى مستودع واحد وصلاحية القراءة، ويتحقق من المستودع والـSHA قبل تنزيل الأرشيف. التنزيل محدود الحجم والمهلة ويقبل تحويل GitHub للأرشيف على نطاق ثابت. التحليل بعدها داخل عامل الفحص بلا شبكة. إزالة الربط تمنع الاستيراد اللاحق، ومراجع اللقطات المقبولة تفضل في تقاريرها. إذا إعداد GitHub غير متوفر، يظل رفع ZIP متاحًا. [GitHub installation tokens](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/generating-an-installation-access-token-for-a-github-app) · [GitHub ZIP archives](https://docs.github.com/en/rest/repos/contents#download-a-repository-archive-zip)

## الاستيراد وربط الأدلة

استيراد ZAP يقبل المعرّفات 10020 و10021 و10035 و10038. يطابق أصل الموقع وعناوين المواضع المقبولة، ويحتفظ بالمعرّف والنص الآمن والعدادات. التقرير يعرض التنبيهات المستبعدة منفصلة، وغياب تنبيه عن الملف يظهر كغير منطبق. المقارنة الآلية بين فحصين من ZAP أو HAR متوقفة لحين توفر دليل قابل للمقارنة. [قواعد ZAP](https://www.zaproxy.org/docs/alerts/)

اضبط مرجع الموقع في سياسة المشروع قبل رفع الكود ودليل الويب. من تقرير المشروع افتح «الأدلة المرتبطة» واختار تقريرًا من نفس الأصل. المالك أو المدير يقدر يضيف الرابط أو يزيله. من يقدر يقرأ التقرير يقدر يتنقل للرابط. كل تقرير يحتفظ بنتائجه ومصدره وإصداره. قاعدة البيانات تربط طرفي العلاقة بمعرّفات مصدر داخل نفس المؤسسة والمشروع وتقفل التكرار.

## سجل التحقق المحلي

اتفعّلت صورة `marsad-platform:phase11-release` على [مرصد المحلي](http://127.0.0.1:8765/) يوم ٢١ نوفمبر ٢٠٢٦. نجح ١٩٨ اختبار Python وثماني حالات فرعية. اختبار CLI الاختياري اتخطّى في مجموعة الاختبارات العامة. نجحت رحلة المتصفح لرفع الملفات المدعومة، وإدارة روابط الأدلة، وتنزيل PDF وSARIF. ترقية نسخة PostgreSQL مستعادة من `0009` إلى `0011` حافظت على الأعداد وبصمة التقارير. اختبار GitHub استخدم خدمة محاكية، والتثبيت الفعلي محتاج إعداد App وربطه بالمؤسسة. رفعت عينة 3D Card إلى محلّل معزول، واتسجل فيها الملفان `index.html` و`style.css` كمقروءين.
