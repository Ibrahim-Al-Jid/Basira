# مساحة العمل ومدخلات الفحص

الـOverview بتعرض اسمك ونشاط مختصر حسب المشروع المختار. التنقل العام فيه مكان واحد للمشاريع والفحوصات والتقارير، وبعد الدخول اللوجو بيرجع للـOverview. صفحة المشاريع بتجمع كل مشروع تحت مؤسسته وتعرض أقسام النشاط وإدارة المدخلات والوصول والمراجع في سياق المشروع.

من الحساب تقدر تشوف الاسم الأول واسم العائلة والـusername وتاريخ إنشاء الحساب، وتعدّل الاسم والـusername. الحسابات الموجودة تستخدم نفس بيانات الدخول وتقدر تضيف اسمها من البروفايل. إرسال الدعوة وإدارة صلاحيات المشروع تفضل مع مالك المؤسسة أو أصحاب الدور المصرّح.

## اختار المصدر من New scan

| المدخل | المطلوب | التقرير |
|---|---|---|
| كود المشروع | ZIP من ملفات المصدر والإعدادات. | نتائج مجمعة من الملفات المؤهلة، مع المسارات والأدلة والإصلاحات وتغطية الأدوات. |
| موقع ويب | لقطة HAR منقّحة من المتصفح. عنوان الموقع اختياري للربط. | مراجعة للاستجابات المحفوظة حسب الأدلة والسياسة. |
| وصف API | ملف OpenAPI 3.0 أو 3.1 بصيغة JSON وفيه `info` و`paths`. | جرد لعمليات المسارات والمصادقة المعلنة والمراجع، وملاحظات عن HTTP والوصول المعلن والمراجع التي تعذر حلها. |
| صفحة أو إعدادات | ملف HTML واحد أو حزمة JSON للإعدادات. | نتائج تخص المدخل المختار. |

السقف الحالي ٢ ميجابايت للرفع، و٨ ميجابايت بعد فك ZIP، و٢٠٠ عنصر ومليون بايت للملف النصي داخل ZIP. التحليل بيقرأ الأنواع النصية المدعومة وبيتجاوز الملفات الثنائية. المشروع اللي عنده سياسة محفوظة يلتزم بالأنواع المسموحة فيها. المالك أو المدير يقدر يغيّرها من إدارة المشروع. [الحدود وعزل التحليل](../PLATFORM.md)

عنوان الموقع يضاف كمرجع للدليل، ولو المشروع محدد أصل في السياسة لازم العنوان يطابقه. ارتباط الدليل بالعنوان تصريح من رافع الملف. OpenAPI يراجع الوثيقة داخل حاوية التحليل ويُسجّل المراجع خارجها كمراجع غير محلولة. المصادقة في التقرير وصف للعقد المرفوع. تقارير ZIP وHAR وOpenAPI قابلة للتصدير من نفس واجهة التقارير. [مواصفة OpenAPI](https://spec.openapis.org/oas/v3.1.1.html)

## التحقق المحلي

اتفعّل تحديث `marsad-platform:workspace-intake` يوم ٢١ نوفمبر ٢٠٢٦. مسار [اختبار رفع المصادر](../../tests/browser_source_intake.py) جرّب ZIP متعدد الملفات وHAR مع عنوان وOpenAPI من الواجهة. واختبارات تسجيل الدخول والدعوات ومراجعة التقارير والتصدير نجحت. الترحيل `platform_profiles_0009` اتجرب على نسخة من قاعدة البيانات قبل تفعيله، واتطابقت أعداد الحسابات والمشاريع والتقارير وبصمة تقرير المشروع بعد التفعيل.
