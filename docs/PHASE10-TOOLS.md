## العزل وتغطية المدخلات

- Docker يشغّل عامل الفحص `scanner` بدون شبكة، بصلاحيات محدودة، ونظام ملفات للقراءة فقط وملفات مؤقتة على `/tmp`. عامل الفحص يمرّر أسماء ووسائط ثابتة للأدوات. ملفات الرفع تدخل كبيانات ولا تبدأ بناء المشروع أو تثبيت تبعياته أو تنفيذ أوامره.
- Gitleaks يفحص ملفات نصية مستخرجة داخل مجلد مؤقت، بقواعده المدمجة. لا يفحص تاريخ Git أو الأرشيفات المتداخلة. إعدادات Gitleaks وملفات التجاهل المرفوعة وتعليقات `gitleaks:allow` لا تتحكم في نتيجة الفحص.
- OSV يقرأ نسخة محلية لمجموعة PyPI. يمرّر المحوّل أسماء الحزم والإصدارات المثبّتة المطابقة للصيغة فقط. لو الملف فيه مراجع لملفات تانية أو Git أو نطاقات أو شروط بيئية أو صيغة pin غير مدعومة، يبان النقص في التغطية مع الحفاظ على أي نتائج صالحة. تطابقات npm المقدّمة داخل حزمة إعدادات تفضل في المحوّل الداخلي.
- الحدود الحالية لكل ملف رفع ثابتة عند 2 MB، وفك اللقطة عند 8 MB، و1 MB للملف المستخرج، و200 عنصر ZIP. المعالجة تضيف حدود 8 ثوانٍ لـGitleaks و22 ثانية لـOSV، و2 MB لمخرجات كل أداة و1000 ملاحظة منها.
- فقدان ملف قاعدة البيانات أو الأداة، تجاوز المهلة أو الحجم، أو رد معطوب ينتج تقريرًا جزئيًا عند انطباق الأداة، ويحافظ على النتائج اللي اكتملت. ملف ZIP فاسد أو مدخل يتجاوز حدود الرفع بيرجع خطأ تجهيز واضح.

## عقد التقرير

- `SRC-01` لبصمة سر من Gitleaks و`SCA-01` لتنبيه PyPI من OSV. هما صفّان إضافيان في تغطية فحص الملفات لما الأدوات تكون في خطته. كتالوج القواعد الداخلية وملفات الفحص القديمة محتفظين بنفس المعرفات.
- كل دليل بيعرف الأداة وإصدارها ومرجعها الأصلي في `origins`. البصمة مبنية على القاعدة والمسار والسطر والدليل المحجوب. تكرار الملاحظة بنفس البصمة بيتحسب مرة واحدة. لو ملاحظة سر مطابقة لنتيجة مرصد في نفس الموضع، الملاحظتان بيشتركوا في صف نتيجة واحد. التغطية بتسجل عداد النتائج المميزة، وحالة الدمج `merged_observations` عند عدم وجود نتيجة منفردة من الأداة.
- تنبيه PyPI بيحفظ معرّفه وأسماءه المترادفة والحزمة والإصدار والمنظومة وتاريخ لقطة قاعدة البيانات. عرض التقرير وPDF بيحافظ على الموضع والنص الموحّد، وتصدير JSON وSARIF بيقدموا الحقول المنظمة. JSON يحافظ على التوافق مع تقارير Phase 9. SARIF يوثّق البصمة في `partialFingerprints` والمصادر والتنبيه في `properties`.
- مخرجات الأدوات الأصلية مؤقتة. بيانات `Secret` و`Match` ومقتطفات المصدر لا تنتقل إلى نتائج Gitleaks المعروضة. الدليل رسالة ثابتة عن نوع التوقيع ويُعرض كملاحظة تستلزم مراجعة. stderr للأدوات غير معروض للمستخدم وسبب الإخفاق رمز محدد.

## إعادة التحقق

```powershell
python -m pytest backend/test_source_adapters.py -q
```

اختبار الأدوات الفعلية يستخدم نفس حدود عامل الفحص وملفات الأدوات المثبتة وصورة بدون شبكة. شغّل نفس ملف الاختبارات مع `MARSAD_REAL_ADAPTERS=1` داخل حاوية اختبار فيها pytest، وبنفس `/opt/marsad-tools` و`/opt/marsad-osv` من صورة التشغيل. في جولة القبول، نجحت 6 اختبارات بروتوكول ووحدة، ونجح اختبار CLI الفعلي للحالات الإيجابية والسلبية في 24.73 ثانية للحالتين معًا. اختبار الوحدة يحاكي غياب قاعدة البيانات والمهلة وردًا معطوبًا وحجم الرد الزائد ويتحقق من حفظ نتائج الأدوات الأخرى.

المحللات الخارجية قابلة للتعطيل بإزالة معرفها من `MARSAD_SOURCE_ADAPTERS` عند التطبيق وعامل الفحص. افتراضيًا صورة التشغيل تشمل لقطة PyPI الرسمية بتاريخ **2026-11-21**، الجيل `1795219387680825`، والـSHA-256 `fc59fe15b782dd1ed7db71464d4a70268dac9ee3ab595da28875ad5756896834`. تحديث اللقطة يحصل وقت بناء صورة، مع تحديث تاريخها وتثبيت بصمتها وإعادة اختبار القبول. [ملف البناء](../Dockerfile) · [لقطة OSV](https://osv-vulnerabilities.storage.googleapis.com/PyPI/all.zip?generation=1795219387680825)

لإعادة تجربة المرشحين داخل Docker بدون شبكة، اربط مجلد `tests/fixtures/phase10` للقراءة فقط عند `/fixtures`. استخدم صورة CE ذات البصمة `sha256:6e1b04340e60e910fbb4ddbf3c857ab0918f064417ad5ac530014ccb3cf8c8f1`، وTrivy Linux amd64 من الأرشيف الرسمي بالبصمة `bc0fc726e017b8927a62b2d3531d7a84ee01769daf5c99ed866dced54089fdbf`. جهّز `/tmp` مؤقتًا واستخدم الأوامر داخل حاوية كل أداة.

```sh
HOME=/tmp SEMGREP_SETTINGS_FILE=/tmp/settings.yml semgrep scan \
  --config /fixtures/semgrep-rules.yaml --metrics off --disable-version-check \
  --timeout 8 --max-memory 256 --jobs 1 --no-git-ignore --json /fixtures/semantic-sample.py

trivy --cache-dir /tmp/trivy config --skip-version-check --skip-check-update \
  --tf-exclude-downloaded-modules --timeout 15s --format json /fixtures
```
