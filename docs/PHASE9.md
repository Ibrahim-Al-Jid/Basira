# Phase 9 | سياسة الفحص والأدلة والتقارير

المسار الأساسي يبدأ بالصفحة التعريفية ثم الحساب والمشروع. شاشة التقرير بتعرض الملخص والنتائج أولًا وبتخلي أدلة النتيجة، التغطية الكاملة، التنفيذ الفني، المقارنة، المراجعة، والصيغ الإضافية في أقسام بتتفتح عند الطلب. ملف PDF فيه النطاق والملخص والنتائج والإصلاحات، مع دليل وموضع ممثل لكل نوع وعدد المواضع الكلي. كل المواضع تفضل متاحة في التقرير الكامل والتصدير المنظم. PDF يشتغل بالعربي والإنجليزي بخط Noto Sans Arabic وتشكيل HarfBuzz. [تشكيل النص في fpdf2](https://py-pdf.github.io/fpdf2/TextShaping.html)

## عقود الخادم

واجهة العقود موجودة في `/docs` و`/openapi.json`. مسارات المشاريع أدناه نسبية لـ`/api/platform/projects/{project_id}`.

| العقد | البيانات والصلاحية |
|---|---|
| `GET /scan-profile` | نسخة النطاق الحالية، أنواع الملفات اللي لها أدوات متاحة، حد البايتات، مهلة الملف الخام، وأدوات كل مدخل بإصداراتها. الاختيار المتاح للموديل يحتاج تصريح تشغيل وإعداد مشروع وبوابة جاهزة. |
| `POST /scans` | الطلب الجديد يحمل نسخة النطاق وإقرار صلاحية مراجعة الملف. الخادم يتحقق من النسخة ونوع المدخل وإعداد الموديل وقت الحجز. `Idempotency-Key` يمنع تكرار نفس الإرسال. الطلبات القديمة تفضل صالحة للفحص المحلي. |
| `GET /technical` | للمالك والمدير. تعرض حالة المحولات وحدود الوكلاء وأذونات الأدوار. حالة البوابة المحلية تثبت وجود إعداد صالح للبوابة ومفتاح قابل للقراءة. اختبار اتصال المزوّد نفسه يتم وقت طلب الإثراء. |
| `GET /scans/{scan_id}/provenance` | للقارئ المصرّح. ترجع أصلًا معلنًا إن وُجد، وبصمة الملف، وإصدار النطاق والقواعد والأدوات، وعدد مواضع الأدلة. تقارير الإصدارات السابقة تُقرأ وتُصدّر بعقدها وقت غياب بيانات المصدر الإضافية. |
| `GET /scans/{scan_id}/evidence` | مواضع مرقمة ومجزأة بالصفحات، بمعرف القاعدة وسطر واسم مسار منقّح وبصمة أثر الدليل. |
| `GET /reports/{report_id}/download?format=pdf&lang=ar` | تنزيل PDF تحت صلاحية تنزيل التقرير نفسها، ويدعم `en`. رابط المختبر المقابل هو `/api/reports/{report_id}/download` ومرتبط بجلسة التقرير. |

مثال لأجزاء طلب مشروع راجع النطاق. العميل يضيف محتوى base64 للملف الحقيقي في `content` ويرسل `Idempotency-Key` في الـheader.

```json
{
  "kind": "html",
  "name": "review.html",
  "content": "PHA+U2FtcGxlPC9wPg==",
  "scope_version": 0,
  "acknowledge_scope": true
}
```

اختيار الموديل عند ظهوره يضيف `"model_connection": "openrouter-default"`. كلمة المرور ومفتاح المزوّد واسم ملف السر خارج عقد طلب الفحص.

## عزل البيانات والتتبع

- الفحص يثبت SHA-256 للملف ونسخة النطاق والقواعد وقائمة المحوّلات. العامل بيتحقق من البصمات قبل التحليل. أثر كل موضع له رقم وبصمة مستقلة بعد التنقيح.
- عنوان الموقع بيكون مرجعًا صرّح به المشروع، وأصل الرصد الخارجي يحتاج الإثبات المقرر في Phase 11. العامل يحلل الملف معزولًا. التقرير الفني يعرض أصل العنوان المعلن بدون المسار.
- الترحيل `platform_provenance_0006` أضاف جداول المصدر والأدلة بعزل PostgreSQL وبصلاحيات إضافة وقراءة لدور التطبيق. محتوى الملف الخام يُمسح عند اكتمال الفحص أو فشله أو إلغائه. بعد ١٥ دقيقة يتوقف قبول تشغيله، والـDispatcher ينظف الطلبات المنتهية دوريًا أثناء عمل الخدمة.
- كتالوج القواعد يحتفظ بالـ١٠٠ معرّف. المخطط يفصل قواعد الضعف عن إمكانيات المحولات حسب نوع الدليل. المحول المدعوم في العادة لو تعطل في النسخة الحالية يظهر في التغطية كتخطي أو خطأ مع تقرير جزئي.
- الخادم يراجع إعداد المشروع وصلاحية مقدم الطلب قبل حجز الإثراء. الموديل يستقبل معرّفات القواعد وأعدادها فقط. الحجز بسقف طلب واحد وما يصل إلى ١٢٠٠ توكن مخرج. يرجع التقرير المحلي لو البوابة تعطلت، واسم الموديل يتسجل لما الإثراء ينجح. [إعداد اتصال الموديل](PLATFORM.md#إضافة-إثراء-openrouter)

## واجهة الاستخدام

- الشريط بيتحرك تلقائيًا عند تفعيل الحركة في إعدادات الجهاز. تفضيل تقليل الحركة يعرض المجالات ثابتة.
- صفحة الدخول والتسجيل بتدعم العربي والإنجليزي والثيمين. الخروج من إعدادات الحساب، والخيارات الفنية الخاصة بالمشروع داخل قسم إدارة قابل للفتح.
- الكتالوج والمختبر متاحين بروابطهم التقنية. تنقل الصفحة العامة وزر بدء المشروع يقودوا لرحلة الحساب.

## قبول النسخة المحلية

نجح بناء الواجهة وصورة Docker، ونجح `npm test` بـ١٦٧ اختبارًا و٨ حالات فرعية. Chromium غطّى التصميم العربي والإنجليزي عند ٣٢٠ و٣٩٠ و٥٦٦ و١٢٨٠ بكسل، وإخفاء روابط العرض والكتالوج من الواجهة العامة. قبول المشاريع غطّى التسجيل والخروج من الإعدادات، والإقرار قبل إرسال الملف، والفحص الخلفي، وفتح التقرير بعد إعادة الدخول. احتُفظ بالتصديرات القديمة واختُبرت المقارنة والمراجعة وSARIF. خرج PDF عربي وإنجليزي واتراجع إخراجهما بصريًا. اتصال OpenRouter اتختبر باستجابات تجريبية تشمل حالة البوابة، وإبطال الصلاحية، وتدوير ملف المفتاح، ورفض محتوى خارج الحقائق المسموح بها.

استعدنا قاعدة PostgreSQL قبل الترقية في بيئة معزولة، وانتقل المخطط من `platform_password_0005` إلى `platform_provenance_0006` مع مطابقة الحسابات والمشاريع والتقارير. اتفعّلت النسخة على نفس اسم مشروع Compose وعنوان `127.0.0.1:8765`، وتطابقت بيانات التقارير الخمسة القديمة في SQLite. النسخة السابقة من صورة التشغيل محفوظة باسم `marsad-platform:pre-phase9`، ونسخ البيانات الخاصة موجودة تحت `%LOCALAPPDATA%/MarsadBackups`.
