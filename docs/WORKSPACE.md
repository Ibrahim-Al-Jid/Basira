# تجربة مساحة العمل

بصيرة يبدأ من المشروع والمصدر اللي المستخدم اختاره. الصفحة الرئيسية بتوضح المدخلات المتاحة، ومجالات التغطية، وإزاي تقرير الأدلة بيتبني. المختبر على مسار منفصل، والعينة فيه اختيار صريح. فحص المشاريع على الملفات المرفوعة وسياسة المشروع. عنوان الموقع في السياسة مرجع للربط بين الأدلة.

## خريطة المسارات

| المسار | الاستخدام |
|---|---|
| `/` | تعريف بالموقع، معاينة تحليل متحركة، المجالات السبعة، والتقييم المرجعي. |
| `/signin` و`/dashboard` | تسجيل الدخول ولوحة النشاط. الدخول من رابط عميق في المشروع يحافظ على مسار العمل. |
| `/projects` | إنشاء مؤسسة ومشروع، نشاط المشروع وتقاريره وإدارة النطاق والوصول حسب الدور. |
| `/new-scan?project=…` | اختيار مشروع، رفع ملف من البداية، مراجعة السياسة ونطاق الملف، ثم الإرسال. |
| `/scans` و`/projects/:id/scans/:scan` | تاريخ فحوصات المشروع، ثم متابعة الأحداث الفعلية والإلغاء وفتح التقرير عند توفره. |
| `/findings?project=…&report=…` | رابط توافق يفتح نتائج التقرير في مسار التقارير. |
| `/reports` و`/reports/:id` | اختيار المشروع وفتح التقرير. الروابط القديمة مع `?project=…` تفضل مدعومة. التقرير يبدأ بملخص ونتائج وتنزيل PDF، وفيه تفاصيل إضافية تُفتح عند الطلب. |
| `/reports?scope=demo` | تقارير المختبر المرتبطة بجلسة صاحب التقرير. روابط المختبر القديمة تفضل صالحة. |
| `/settings` | الحساب والتفضيلات وقبول الدعوات وتسجيل الخروج واتصال الموديل حسب الصلاحية. |
| `/demo` | صفحة تحويل فقط: تفتح مساحة العمل أو صفحة الدخول. |

FastAPI بيخدم مسارات الواجهة المحددة صراحة. التطبيق يفتح المسار المباشر من السيرفر، وطلبات API المجهولة تفضل ترجع خطأ API. صلاحيات وعقود تقارير المشاريع على الخادم زي باقي المسارات.

## الهوية البصرية والتفاعل

الثيم الداكن افتراضي والفاتح اختياري. اللغة والثيم يتضبطوا من «الحساب»، والاختيار محفوظ في المتصفح. العناوين الإنجليزية تستخدم **Space Grotesk**، والواجهة تستخدم **Inter** للاتيني و**IBM Plex Sans Arabic** للعربي. الخطوط بتتخدم من التطبيق. شريط المجالات ومعاينة التحليل بيتحركوا تلقائيًا، ومع تفضيل تقليل الحركة تُعرض المجالات ثابتة. عناصر التحكم قابلة للوصول بالكيبورد. روابط التقارير القديمة بقيمة `lang` تفتح بنفس اللغة، ونسخة PDF باللغة التانية متاحة جوّه «صيغ تنزيل إضافية».

التقييم الداخلي في توثيق المشروع مبني على **١٨ حالة اصطناعية**، انطبقت عليها **٢٥ قاعدة** مرة على الأقل، و**٥٤ عينة زمنية**. تفاصيل القياس والحدود في [قبول الإصدار الحالي للمحرك](RELEASE.md#التقييم). معالج الفحص بيعرض نوع المدخل ونطاقه من السياسة الحالية. 

## التحقق

شغّل `npm test` و`npm run build`. لتجربة المتصفح استخدم Compose معزول ببيانات اختبار وبيئة حسابات محلية، وشغّل `python tests/browser_workspace.py` و`python tests/browser_password_login.py` و`python tests/browser_release.py --password-account`. لاختبار الحساب والدعوات والموديل، فعّل بوابة الموديل في بيئة الاختبار وشغّل `python tests/browser_account.py`. البيئة الافتراضية لاختبارات المشاريع على `127.0.0.1:8776`. اختبار `tests/browser_local_build.py` يستخدم جلسة مختبر منفصلة كما في خطوات اختبار المختبر. اختبارات المتصفح محتاجة Playwright: ثبّته مرة واحدة بـ`python -m pip install -r requirements-browser.txt` وبعدها `python -m playwright install chromium`.

### سجل قبول مساحة العمل

- Chromium على ٣٢٠ و٣٩٠ و١٢٨٠ CSS px بالعربي والإنجليزي. اختبار إعادة التدفق، الكيبورد وقائمة الجوال، الثيم واستمراره بعد التحديث، إيقاف الحركة و`prefers-reduced-motion`. تباين أزواج الألوان المفحوصة للنصوص الأساسية والأزرار حقق 4.5:1 أو أكتر، وحدود عناصر التحكم المقاسة حققت 3:1 أو أكتر. [WCAG 2.2](https://www.w3.org/TR/WCAG22/) · [Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)
- قبول المشروع في Compose غطّى إنشاء الحساب والمشروع، الملف الفارغ عند البداية، الرفع والفحص الخلفي، إعداد نطاق التقرير، تبديل لغة التقرير، واختيار الأدلة. اختبارات المتصفح السابقة غطّت روابط وتقارير المختبر، والمقارنة، وإعادة الدخول وعزل حساب آخر.
- اختبار التطبيق `npm test` نجح بـ١٥٧ اختبارًا و٨ حالات فرعية، وبناء Vite وDocker نجحوا. اتفعّلت الصورة المختبرة على `127.0.0.1:8765` بنفس موارد Compose والـ١٠٠ قاعدة. طابقنا محتوى التقارير المحلية الخمسة مع النسخة الاحتياطية. صورة ما قبل التفعيل محفوظة محليًا بالوسم `basira-platform:pre-phase8`.
