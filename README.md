# مرصد | Marsad

مساحة عمل لمراجعة أمان ملفات المشاريع. اختار مشروعًا ومصدر دليل، وتابع الفحص وافتح تقريرًا بالعربي أو بالإنجليزي، مع الوضع الداكن والفاتح.

## شغّل مرصد محليًا

لو Docker شغّال، افتح [مرصد](http://127.0.0.1:8765) أو [مساحة العمل](http://127.0.0.1:8765/dashboard). إعداد حسابات المشاريع وطريقة تشغيل بيئتها في [دليل تشغيل المنصة](docs/PLATFORM.md).

لتشغيل المختبر فقط في بيئة تطوير مستقلة، استخدم الأوامر دي من مجلد `sentinel` قبل تشغيل خدمة تانية على المنفذ 8765:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
npm --prefix frontend ci
npm run build
npm start
```

افتح [المختبر محليًا](http://127.0.0.1:8765/demo)، اختار ملف HTML أو الصقه أو استخدم العينة. وضع **موسّع** هو الاختيار الافتراضي، وتقدر ترجع للوضع الأساسي من حقل «نطاق الفحص». [كتالوج الفحوصات المحلي](http://127.0.0.1:8765/checks) يعرض الـ١٠٠ قاعدة وأدواتها. إثراء OpenRouter اختياري. من [تقارير المختبر](http://127.0.0.1:8765/reports?scope=demo) افتح تقريرك داخل جلسة المتصفح صاحبة التقرير، أو نزّل HTML بالعربي أو الإنجليزي أو JSON. [مرجع المشروع](docs/PROJECT.md)

## الحالة

- خمسة أدوار فعلية في LangGraph. الخادم بيحلل HTML محليًا ويخزن التقارير في SQLite باسم جلسة المتصفح. عند تعطل إثراء OpenRouter يقدر يكمل بتقرير محلي.
- كتالوج الإصدار فيه ١٠٠ فحص دفاعي. المختبر الموسّع يشغّل القواعد اللي تنطبق على HTML. المشاريع تدعم كمان ZIP وHAR ولقطات JSON، وتضيف مقارنة الفحوصات وتعليقات وحالات النتائج وتصدير PDF بالعربي والإنجليزي وSARIF. [دليل تشغيل المنصة](docs/PLATFORM.md)
- نسخة المشاريع المحلية بتدعم إنشاء حساب بإيميل وكلمة مرور خاصة بمرصد. تقدر تستخدم OIDC لتسجيل حسابات المؤسسة لما إعدادات المزوّد تتوفر. [صفحة المشاريع المحلية](http://127.0.0.1:8765/projects)
