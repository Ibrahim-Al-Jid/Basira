# مرصد | Marsad

مساحة عمل لمراجعة إعدادات الأمان الظاهرة في HTML. اختار ملف من جهازك أو الصق المصدر، تابع تنفيذ خمس أدوار عبر LangGraph، وافتح التقرير واحفظ نسخة عربية أو إنجليزية.

## شغّل مرصد محليًا

لو Docker شغّال، افتح [مرصد](http://127.0.0.1:8765) أو [المشاريع](http://127.0.0.1:8765/projects). إعداد حسابات المشاريع وطريقة تشغيل بيئتها في [دليل تشغيل المنصة](docs/PLATFORM.md).

لتشغيل المختبر فقط في بيئة تطوير مستقلة، استخدم الأوامر دي من مجلد `sentinel` قبل تشغيل خدمة تانية على المنفذ 8765:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
npm --prefix frontend ci
npm run build
npm start
```

افتح [مرصد محليًا](http://127.0.0.1:8765)، ومن شاشة المختبر اختار ملف HTML أو الصقه أو استخدم العينة. وضع **موسّع** هو الاختيار الافتراضي، وتقدر ترجع للوضع الأساسي من حقل «نطاق الفحص». [كتالوج الفحوصات المحلي](http://127.0.0.1:8765/checks) يعرض الـ١٠٠ قاعدة وأدواتها. إثراء OpenRouter اختياري. من [سجل التقارير](http://127.0.0.1:8765/reports) افتح تقريرك داخل جلسة المتصفح صاحبة التقرير، أو نزّل HTML بالعربي أو الإنجليزي أو JSON. [مرجع المشروع](docs/PROJECT.md)

## الحالة

- خمسة أدوار فعلية في LangGraph. الخادم بيحلل HTML محليًا ويخزن التقارير في SQLite باسم جلسة المتصفح. عند تعطل إثراء OpenRouter يقدر يكمل بتقرير محلي.
- كتالوج الإصدار فيه ١٠٠ فحص دفاعي. المختبر الموسّع يشغّل القواعد اللي تنطبق على HTML. المشاريع تدعم كمان ZIP وHAR ولقطات JSON، وتضيف مقارنة الفحوصات وتعليقات وحالات النتائج وتصدير SARIF. [دليل تشغيل المنصة](docs/PLATFORM.md)
- نسخة المشاريع المحلية بتدعم إنشاء حساب بإيميل وكلمة مرور خاصة بمرصد. تقدر تستخدم OIDC لتسجيل حسابات المؤسسة لما إعدادات المزوّد تتوفر. [صفحة المشاريع المحلية](http://127.0.0.1:8765/projects)
