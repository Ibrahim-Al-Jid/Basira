# مرصد | Marsad

مساحة عمل لمراجعة أمان ملفات المشاريع. اختار مشروعًا ومصدر دليل، وتابع الفحص وافتح تقريرًا بالعربي أو بالإنجليزي، مع الوضع الداكن والفاتح.

## شغّل مرصد محليًا

**على جهاز Windows جديد** شغّل Docker Desktop، وبعدها نفّذ الأمر ده من جذر الريبو في PowerShell علشان تفتح نسخة المشاريع بالحسابات:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\ops\start-local.ps1
```

افتح [تسجيل الدخول المحلي](http://127.0.0.1:8765/signin) واختار «إنشاء حساب» للتثبيت الجديد. بيانات الحسابات والمشاريع بتتخزّن في PostgreSQL على الجهاز اللي شغّلته عليه. تفاصيل التشغيل اليدوي وتشخيص مشاكل الدخول في [دليل تشغيل المنصة](docs/PLATFORM.md).

لتشغيل المختبر فقط في بيئة تطوير مستقلة، استخدم الأوامر دي من مجلد `sentinel` قبل تشغيل خدمة تانية على المنفذ 8765:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
npm --prefix frontend ci
npm run build
npm start
```

افتح [المختبر محليًا](http://127.0.0.1:8765/demo)، اختار ملف HTML أو الصقه أو استخدم العينة. وضع **موسّع** هو الاختيار الافتراضي، وتقدر ترجع للوضع الأساسي من حقل «نطاق الفحص». من [تقارير المختبر](http://127.0.0.1:8765/reports?scope=demo) افتح تقريرك داخل جلسة المتصفح صاحبة التقرير، أو نزّل HTML بالعربي أو الإنجليزي أو JSON. [مرجع المشروع](docs/PROJECT.md)

## الحالة

- خمسة أدوار فعلية في LangGraph. الخادم بيحلل HTML في المختبر محليًا ويخزن التقارير في SQLite باسم جلسة المتصفح. المشاريع تدعم إثراء اختياري من «الحساب ← اتصال الموديل»، وبتكمل بتحليل محلي لو المزوّد تعطل.
- كتالوج الإصدار فيه ١٠٠ فحص دفاعي. المختبر الموسّع يشغّل القواعد اللي تنطبق على HTML. المشاريع تدعم كمان ZIP وHAR ولقطات JSON، وتضيف مقارنة الفحوصات وتعليقات وحالات النتائج وتصدير PDF بالعربي والإنجليزي وSARIF. [دليل تشغيل المنصة](docs/PLATFORM.md)
- نسخة المشاريع المحلية بتدعم إنشاء حساب بإيميل وكلمة مرور خاصة بمرصد. تقدر تستخدم OIDC لتسجيل حسابات المؤسسة لما إعدادات المزوّد تتوفر. [صفحة المشاريع المحلية](http://127.0.0.1:8765/projects)
